# 硬件与版本清单

## 天翼语音网关（现役）

- 页面型号：MSG2600E-XES-8E8V-WS3
- 管理地址：`192.168.1.1`
- 能力：8 路运营商 IMS 用户、8 路 FXS/POTS、本地号码和业务状态监控。
- 2026-11-14 状态：八个 IMS 用户均注册成功，八个 POTS 口均开启且业务正常。
- 角色：现役运营商托管 IMS 客户端和 FXS 网关，接替下述旧 A8-C。

不得在仓库保存 Web 密码、IMS 密码或运营商服务器凭据。设备配置已通过
保存和暖重启回读，但尚未完成断电冷启动演练。

## 天翼 A8-C / MSG2200-T4（历史设备）

- 页面产品名：天翼宽带政企网关
- 页面型号：MSG2200-T4
- 现场标签型号：天翼宽带政企网关 A8-C
- 硬件版本：K
- 软件版本：V0300-0200509-E
- 子版本：3.30.314.20230602
- 能力：IMS-SIP、SIP、H.248；8 路 FXS/POTS；独立 Voice_R_43 和管理接口。
- 管理：LAN1 为 `192.168.1.0/24`，A8-C 为 `192.168.1.1`。
- 历史验证：实体话机接入后可呼出、可接听；八个号码曾由电信注册。

能力边界：该设备曾是运营商托管的 IMS 客户端和 FXS 网关。其 Web UI 没有提供
把已注册线路反向导出为用户侧 SIP trunk 的功能。把 Outbound Server 改成
R640/MikroTik 会中断运营商注册，不能作为长期方案。

## Grandstream GXW4108

- 型号：GXW4108
- 硬件：2.0 Rev A（SIP User-Agent 报文中显示 `HW 2.0`）
- 固件：1.4.1.5
- 能力：8 路 FXO 到 SIP，支持一阶段/二阶段拨号、G.711、RFC2833。
- 状态：Grandstream 已 EOL；1.4.1.5 是官方最终固件。
- 网络：`192.168.88.249`，MikroTik ether10。
- 物理：FXO0—FXO7 分别接 A8-C 的 8 个 FXS 口。

已知限制：老固件字段解析严格。固定号码生产模式必须同时使用每路独立 SIP
端口和八个独立调度组；当前值为
`rr:1;rr:2;rr:3;rr:4;rr:5;rr:6;rr:7;rr:8;`。Stage 2 诊断同时携带
`99 + 端口号`选择码，但不能依赖旧的 `rr:2-8` 轮询组固定物理口。

## MikroTik RB4011

- 型号：RB4011iGS+
- RouterOS：7.23.2 stable
- 角色：三层管理、局域网交换、到 A8-C 管理面的连通。
- 不承担：Asterisk/FreeSWITCH、录音、ASR 或呼叫业务状态。

RouterOS SIP helper/ALG 会重写 SIP/SDP 地址与端口，容易破坏本地 PBX、
NAT 和 RTP 调试。POC 应确认其状态并优先禁用；禁用前先导出配置，且不能
影响其他现网 SIP。

## Dell PowerEdge R640

- 地址：`192.168.88.251/24`，接口 `eno2np1`
- 角色：未来的 Asterisk/FreeSWITCH、AI Agent、录音、ASR/TTS 和业务逻辑。
- 当前：宿主机 FreeSWITCH GXW profile 监听 `192.168.88.251:5160/udp`，八个
  gateway 分别指向 GXW `5060, 5062, 5064, 5066, 5068, 5070, 5072, 5074`。
- 诊断：Python Stage-2 探针使用独立本地 SIP/RTP 端口；成功记录不等于
  `re8ch-voice-gateway` 自动 API 已通过生产验收。

## 线材

天翼网关 FXS 与 GXW4108 FXO 使用 RJ11 直通模拟电话线。语音只使用中间一对
线芯；常见 6P2C、6P4C、6P6C 只要中间一对直通都可工作。现有 15 cm
6P6C 短线可以使用，但应逐条用万用表确认不是交叉线。
