# Retired generated platform inventory

This point-in-time Markdown export is retired. It contained host addresses,
workload names and controller states that became stale after the Cloud SSA
migration, so it must not be used as current inventory, topology or health
evidence.

Current inventory is read through the authenticated platform APIs. Current
delivery evidence comes from Cloud SSA accepted state and receipts; current
health comes from the independent runtime observer. Historical contents remain
available in Git history or may be migrated to the restricted operations Wiki.

Do not regenerate this Markdown snapshot or copy its former host and workload
tables into public documentation.
